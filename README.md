# Perishable Goods Optimization & Dynamic Pricing Engine

An intelligent, machine-learning-powered dynamic pricing system designed to optimize discount strategies for perishable goods. The engine predicts the optimal discount percentage for items based on real-time factors like shelf life, inventory levels, and competitor pricing to accelerate stock clearance while protecting margins.

---

## 🚀 Key Features

* **Data Simulation Engine**: Generates realistic synthetic datasets modeling relationships between inventory attributes and clearance outcomes.
* **XGBoost Regressor Pipeline**: A high-efficiency gradient boosting model trained to predict optimal discounts.
* **Sub-Second API Serving**: A modern **FastAPI** application designed for instant, real-time prediction queries.
* **Fully Structured Inputs**: Strict request validation using **Pydantic** to ensure safe and predictable inputs.

## 🛠️ Installation & Setup

### 1. Install Dependencies
Ensure you have Python installed, then install the necessary dependencies:

```bash
pip install pandas numpy xgboost joblib scikit-learn fastapi uvicorn pydantic
```

### 2. Train the Pricing Model
Execute the training script to simulate historical inventory data, train the **XGBoost Regressor**, evaluate the model's RMSE, and save the serialized weights:

```bash
python train_model.py
```

This will generate a serialized model file named `pricing_engine.pkl` in your root directory.

### 3. Spin up the Real-Time API
Deploy the FastAPI server using Uvicorn:

```bash
uvicorn api:app --reload
```

## 🔌 API Documentation & Usage

Once the server is running, you can access the automatic documentation generated by FastAPI:
* **Swagger UI Docs**: `http://127.0.0.1:8000/docs`
* **ReDoc**: `http://127.0.0.1:8000/redoc`

### Predict Optimal Discount Endpoint

* **Endpoint**: `/predict-discount`
* **Method**: `POST`
* **Content-Type**: `application/json`

#### Request Payload Example

```json
{
  "hours_to_expiry": 12.5,
  "current_stock": 35,
  "competitor_price": 5.99
}
```

#### Response Example

```json
{
  "status": "success",
  "recommended_discount_percentage": 50.4,
  "action": "Apply 50.4% discount immediately to clear stock."
}
```
